# Dataset Sintoma vs Doença

## Descrição

Desvende os mistérios das doenças com nosso Conjunto de Dados Abrangente de Sintomas de Doenças e Perfil de Pacientes. Este conjunto de dados cativante oferece um tesouro de informações, revelando as fascinantes conexões entre sintomas, dados demográficos e indicadores de saúde. Mergulhe na rica tapeçaria de febre, tosse, fadiga e dificuldade para respirar, entrelaçada com idade, sexo, pressão arterial e níveis de colesterol.

## Estrutura do Dataset

O dataset contém as seguintes colunas:

1. **Doença**: O nome da doença ou condição médica
2. **Febre**: Indica se o paciente tem febre (Sim/Não)
3. **Tosse**: Indica se o paciente tem tosse (Sim/Não)
4. **Fadiga**: Indica se o paciente sente fadiga (Sim/Não)
5. **Dificuldade para respirar**: Indica se o paciente tem dificuldade para respirar (Sim/Não)
6. **Idade**: A idade do paciente em anos
7. **Sexo**: O sexo do paciente (Masculino/Feminino)
8. **Pressão arterial**: O nível de pressão arterial do paciente (Normal/Alto)
9. **Nível de colesterol**: O nível de colesterol do paciente (Normal/Alto)
10. **Variável de resultado**: Indica o resultado do diagnóstico (Positivo/Negativo)
